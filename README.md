# HicoForge

Image processing toolkit with chained upscaler flows.

Part of the Hico family of apps (HicoSend, HicoTrade, HicoForge).

## Quick start


## Features

- Multiple AI upscalers (Real-ESRGAN, SwinIR, etc.)
- Flow Tiles: chain multiple processors into a pipeline
- Preview & cull intermediate results
- Auto-update on launch

## Tech

Python 3.10+, PySide6, NVIDIA CUDA recommended.
